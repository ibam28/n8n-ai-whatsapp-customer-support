# n8n AI WhatsApp Customer Support

## Project Goal

Build an AI-powered WhatsApp Customer Support Automation platform using n8n, Evolution API, Ollama, Docker, MySQL, and PHP REST API.

The system automatically receives customer messages from WhatsApp, stores conversations, generates AI responses using a local LLM, and replies back to customers.

---

# Objectives

- Receive WhatsApp messages automatically
- Store conversations in MySQL
- Generate AI responses using Ollama
- Reply automatically to customers
- Support future CRM integration
- Support future Human Handover
